Design system

Every value on this page is read live from css/tokens.css, and every component uses the same classes as the game screens (css/components.css). Rules and rationale: docs/design-system.md. Character: control-deck, instrumented, luminous, legible, spatial.

Color

Semantic tokens only. Color marks meaning and always comes with text or a number (WCAG 1.4.1).

Contrast, measured from saved values

Computed in your browser from the resolved CSS variables. Text needs 4.5:1, control borders 3:1 (WCAG 1.4.3, 1.4.11).

Typography

Orbitron for titles, badges and numerals; Rajdhani for body and labels (R01.2). Nothing below 12 px.

Spacing

Pick by relationship, not by size.

Shape, glow and motion

Radius 4 on controls, 8 on panels. Glow marks meaning only (selected, live, danger) and never animates on its own (R01.1, A04). Hover glow transitions in 150 ms; reduced motion turns it off.

S/D indicator

Color follows the buy chance on 2d6 (roll + indicator ≥ 0), never fixed indicator endpoints (R03.5, conflict 48). Four steps: easy, fair, hard, bad. The number always stays visible.
